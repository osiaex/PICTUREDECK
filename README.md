# PICTUREDECK
这是四川大学2025软件工程第7组的课程设计项目

本项目提供了对第三方AIGC服务的访问客户端，以及其他配套服务，项目各部分内容如下：

| 模块（文件夹）         | 说明     |
| :----------- | :--------------------------------- | 
| Client | Qt开发的客户端 |
|backend | Python flask 服务器后端，处理客户端的请求，访问AIGC等第三方服务 |
|admin_cli|用于统计和管理的后台命令行 |

获取源代码后，为了运行本系统，请注意：
1. 填写`backend\config.py`中缺省的配置项
2. 填写`backend\app\services\js\.env`中缺省的配置项
